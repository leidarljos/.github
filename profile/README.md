# leiðarljós

Memory, a work tracker and a check on every shell command for coding agents (Claude Code, Codex, Cursor and others). It runs on your machine, and each claim is written on purpose, never mined from chat.

**Citation is not a merge.** [`ljos`](https://github.com/leidarljos/ljos) is the seat. [`consensus`](https://github.com/leidarljos/consensus) is DeGroot / Seldon ODE.

| Habitat | Question |
|---|---|
| cards | Frozen working core (`USER.md` / `MEMORY.md`). Human. Read-only. |
| [packset](https://github.com/leidarljos/packset) | What does this seat know, standing? |
| [deedar](https://github.com/leidarljos/deedar) | What did this unit produce? |
| [vissue](https://github.com/leidarljos/vissue) | What does this node stand on, and who agrees? |
| [claimdag](https://github.com/leidarljos/claimdag) | What is this session handing out? |

[ljos-policyd](https://github.com/leidarljos/ljos-policyd) is argv law, not a store. Completing a claimdag node does not close a ticket. [phronesis](https://github.com/leidarljos/phronesis) is the policy library behind that check when the binary is linked to it.
